## Description
Philosophers is the classic Dining Philosophers concurrency exercise. The goal is to implement a correct, deadlock-free simulation where each philosopher is a thread and each fork is protected by a mutex. The program logs state transitions with timestamps and stops on a death condition (or when every philosopher has eaten the required number of times, if provided).

## Instructions
Build the mandatory program:

```bash
cd philo
make
```
Program arguments (all times in milliseconds):
- `number_of_philosophers`: number of philosophers and forks
- `time_to_die`: max time without starting to eat before death
- `time_to_eat`: duration of eating
- `time_to_sleep`: duration of sleeping
- `number_of_times_each_philosopher_must_eat` (optional): stop when all philosophers reach this count

```bash
./philo number_of_philosophers time_to_die time_to_eat time_to_sleep [number_of_times_each_philosopher_must_eat]
```

**Usage Examples**
```bash
# 5 philosophers, stop only on death
./philo 5 800 200 200

# 4 philosophers, stop after each has eaten 7 times
./philo 4 410 200 200 7
```

**Project Structure**
- `philo/` C source for the mandatory part
- `philo/Makefile` build rules (target: `philo`)
